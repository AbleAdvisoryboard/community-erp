# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities responsibly by email:

Contactus@aadvisoryboard.com

Do not open a public GitHub issue for security vulnerabilities.

When reporting, include as much useful information as you can safely share:

- A description of the issue
- Steps to reproduce
- Affected versions or commits, if known
- Potential impact
- Any suggested mitigation

Please do not include real donor, client, user, payment, or production organization data in reports.

## Response Expectations

This is an early-stage open-source project. Security reports will be reviewed as promptly as possible, and confirmed issues will be prioritized based on severity, reproducibility, and potential impact.

## Supported Versions

Public release support is currently limited to the latest published release and the default branch.
